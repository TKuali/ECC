# Panel de Salud de Habilidades (Skill Health Dashboard)

Muestra un panel de salud exhaustivo para todas las habilidades del catálogo, con gráficos sparkline de tasas de éxito, agrupación de patrones de fallo, enmiendas pendientes e historial de versiones.

## Uso

```
/skill-health                    # Vista de panel completo
/skill-health --panel failures   # Solo panel de agrupación de fallos
/skill-health --json             # Salida JSON legible por máquina
```

## Qué Hacer

1. Ejecutar el script `skills-health.js` con la bandera `--dashboard`
2. Mostrar la salida al usuario
3. Si alguna habilidad está en declive, resaltarla y sugerir ejecutar `/evolve`
4. Si existen enmiendas pendientes, sugerir revisarlas

## Paneles

- **Tasa de Éxito (30d)** — Gráficos sparkline con las tasas de éxito diarias por habilidad
- **Patrones de Fallo** — Motivos de fallo agrupados con gráfico de barras horizontales
- **Enmiendas Pendientes** — Propuestas de enmienda a la espera de revisión
- **Historial de Versiones** — Línea de tiempo de capturas de versión por habilidad
